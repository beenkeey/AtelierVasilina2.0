# Заказы через Telegram

## Вариант 1 — только ссылки (рекомендуем на старт)

**Плюсы:** бесплатно, без сервера, идеально для GitHub Pages и ссылок из Instagram.

1. Укажи username в `frontend/public/catalog.json` → `site.telegram` или в `.env.local` → `NEXT_PUBLIC_TELEGRAM`.
2. На сайте кнопки открывают `t.me/...` с **готовым текстом** («Хочу заказать «Название» №…»).
3. Ответы ведёшь вручную в личном или бизнес-чате Telegram.

Для Instagram: одна ссылка в bio → GitHub Pages.

---

## Вариант 2 — бот (когда заявок станет много)

**Плюсы:** меню, сбор имени/телефона/комментария, уведомления тебе, `/start work_123` с карточки товара.

**Минусы:** нужен хостинг 24/7 (не GitHub Pages): бесплатные tier у Railway, Render, Fly.io или домашний ПК.

Схема:

1. [@BotFather](https://t.me/BotFather) → создать бота → токен.
2. На сайте в `NEXT_PUBLIC_TELEGRAM` указать **имя бота** (без @).
3. Ссылки вида `https://t.me/YourBot?start=work_demo-painting-1` — бот понимает, какую работу выбрали.
4. Бот шлёт заявку в твой `ADMIN_CHAT_ID`.

Минимальный каркас — папка `bot/` (можно добавить по запросу).

---

## Что выбрать

| Ситуация | Решение |
|----------|---------|
| Витрина + Instagram, 1–5 заказов в неделю | **Ссылки на личный Telegram** |
| Хочешь «как магазин» с кнопками и историей | **Бот + хостинг** |
| Не хочешь сервер вообще | Ссылки + таблица Google для учёта вручную |

Сайт уже настроен под **вариант 1**; бот — следующий шаг без переделки витрины.
